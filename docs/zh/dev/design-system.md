# Swiftnest App 设计规范

[English](../../en/dev/design-system.md) | 中文

这是 Swiftnest App（`client/`，Tauri 2 + React/TS）的界面规则。气质（克制、留白、层级清楚、内容做主角）借鉴 DSH Go 公开的设计说明，但不使用 DSH Go 的任何代码、素材和品牌，组件全部自己写。

每条规则都要能检查：设计令牌放在 `client/src/design/tokens.ts`，标了 **（测试）** 的规则有单元测试或几何测试。

## 1. 原则

1. **内容是主角。** 界面退后一步：不用装饰性边框、渐变和循环动画。
2. **一屏一个重心。** 每屏只有一个主操作，只有它用强调色。
3. **同一种骨架，同一种表现。** 同类页面的顶部、间距、分组完全一致。
4. **文案短、确定。** 按钮动词开头，不出现内部术语（不说“会话 ID”“Cordis”“profile”）。
5. **能降级。** 模糊、动效、震动都可以关掉，关掉后界面依然完整。

## 2. 页面骨架

只有五种。新页面从中选一种，不发明第六种。

| 骨架   | 用途                         | 顶部                             | 主体                 |
| ------ | ---------------------------- | -------------------------------- | -------------------- |
| 枢纽页 | 首页：对话、Bot、设备        | 大标题，右侧头像按钮             | 分组卡片列表         |
| 详情页 | 一个对话、一个 Bot、一台设备 | 返回、标题加副标题、一个尾部操作 | 内容占满宽度         |
| 列表页 | 搜索结果、历史、插件         | 返回、标题、搜索框               | 虚拟滚动的行         |
| 表单页 | 设置、配对、Bot 编辑         | 返回、标题、保存（主操作）       | 分组的字段           |
| 弹层   | 确认、审批、选择器           | 拖动条、标题                     | 简短内容，操作在底部 |

## 3. 布局

- 间距只取 4 的倍数：`4 8 12 16 20 24 32 40 48 64`。**（测试）**
- 圆角：控件 12，卡片 20，弹层 28，头像全圆。**（测试）**
- 页面边距：手机 16，平板 24，桌面 32。
- 断点：`手机 < 600 ≤ 平板 < 1024 ≤ 桌面`。横屏手机宽度 ≥ 600 时用平板的双栏布局。
- 桌面版加常驻侧栏（对话列表）、可选的第三栏（记忆或详情）和快捷键。
- 对称布局（居中标题、头像网格）写几何测试：左右内边距相差不超过 0.5 px。**（测试）**
- 可点区域至少 44 × 44 px。

## 4. 配色

- 在 **OKLCH** 里从一个强调色推出整套颜色：`generatePalette(accent, mode)` 返回浅色或深色的全部令牌（背景、表面 1–3、主要/次要/弱化文字、边框、强调色、强调色上的文字、成功、警告、危险）。
- 内置 5 套强调色预设，加自定义；安卓 12 起可以跟随壁纸。
- **对比度守卫**：所有文字和背景的组合都满足 WCAG AA（正文 4.5:1，大字和图标 3:1），不满足时生成器自动调整明度。**（测试：每套预设、两种模式）**
- 强调色只给主操作、选中状态和链接；状态色只表示状态。
- 暗色模式是一等公民，默认跟随系统，可以在设置里固定。

## 5. 表面

- “玻璃”表面：半透明表面色加 20 px 背景模糊，用于顶栏、底栏和弹层。
- 不支持模糊、模糊太慢（中低端安卓 WebView）或打开了“降低透明度”时，退回同色的不透明表面。两种情况都要好看。
- 层次靠表面等级（1–3）表达，不靠重阴影。只有弹层用一个柔和的阴影令牌。

## 6. 字体

- 系统字体栈（`system-ui`，中文加 `"PingFang SC", "Noto Sans CJK SC"`）。v0 不打包字体。
- 字号（px / 行高）：大标题 28/34，标题 20/26，小标题 17/22 半粗，正文 16/24，标注 15/20，脚注 13/18，说明 12/16。
- 代码用等宽字体：`ui-monospace, "JetBrains Mono", monospace`。

## 7. 动效

- 时长 150–300 ms，标准缓动 `cubic-bezier(0.2, 0, 0, 1)`。
- 按压：150 ms 内缩到 0.97。
- 导航：手机上从右侧推入、可跟手滑动返回；桌面上淡入淡出。
- 不用弹跳，不用循环装饰。只在等待时显示一个平静的进度指示。
- `prefers-reduced-motion`（或 App 里的开关）打开时，所有时长为 0。**（测试）**

## 8. 图标和文案

- 图标用 Phosphor（MIT），常规粗细 24 px，只有选中的标签页用填充样式。图标按角色在一个映射表（`icons.ts`：`send`、`approve`、`device`……）里统一管理，页面里不直接零散引入。
- 文案短、确定。写“配对设备”，不写“点击这里开始配对”。错误提示说清发生了什么、下一步怎么做。所有文字从第一天起就走国际化（`en`、`zh-CN`）。

## 9. 聊天交互

- **生成中插话或排队**：输入框一直可用；回合进行中发送时，可以选“立即发送”（打断）或“排队”。
- **做完的过程折叠成一行**：一个回合结束后，工具调用和思考折叠成一行（“运行了 4 个工具 · 12 秒”），点开展开。
- **思考胶囊**：模型思考时显示一个小胶囊，带已用时间。
- 改文件时显示**回合改动卡**和 diff；产出文件时显示**产物文件卡**。
- **审批卡**：谁在请求、在哪台设备上、确切的命令或路径，按钮是“批准 / 拒绝”。在聊天里内联显示，同时在你当前使用的设备上弹出弹层。
- 第三方插件产生的**认不出的内容**按通用卡片显示（标题、键值对、原始 JSON 开关），不丢弃。
- **群聊**：每条消息显示 Bot 的头像和名字；输入 `@` 弹出成员菜单。
- 分享卡和对话回放以后再做（不在阶段 0）。

## 10. 长列表和性能

- 聊天记录和所有超过约 50 行的列表都用虚拟滚动。
- 目标是中端安卓机上滚动 60 fps，阶段 0 就在真机上测。

## 11. 不能用的东西

DSH Go 的代码（AGPL-3.0），它的鲸尾标志、Deepy 小鲸鱼、鲸娘桌宠和展示图，以及把 DeepSeek 商标用作我们的名字或标志。Swiftnest 发布前会有自己的品牌。
