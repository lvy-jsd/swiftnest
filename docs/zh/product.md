# Swiftnest 产品蓝图与验收边界

> 2026-11-07 决策快照，状态：待评审的目标契约，**不是已交付功能清单**。采用一次成型设计、并行实现、整体验收；下列分组是职责边界，不是 MVP 阶段。现有运行方式仍以指南和实际代码为准。界面扩展遵循 [面板规范](./ui-kit.md)，历史设计不作为新增功能的唯一依据。

## 1. 产品与平台

一台常开的 Linux 服务器（巢），连接 Linux 桌面端和 Android 端。同一助手、记忆、Bot 和任务跨设备使用；一端可以让另一端本地执行任务，指令与结果全部经服务器中转，不新建端间直连或屏幕串流产品。保留巢、栖点、审批、审计、任务状态机、Tool Ultra 目录和按需加载。

- Linux 桌面外壳选 Electron，Android 外壳选 Capacitor，复用现有 React 界面；当前代码仍是 Tauri，换壳尚未交付。Windows、macOS、iOS 不在本轮交付范围。
- **只有服务器要求 24 小时在线**。手机客户端打开即连接、关闭可休眠；自建推送通知结果，不靠手机后台常驻维持服务。
- Linux 分发支持 Nix module 与 Docker。进程守护、崩溃拉起、任务续跑、数据快照和恢复均须验证。升级用候选实例健康检查后切换、失败退回旧版；有排他状态的内核和写操作必须明确单写者及在途任务交接，不能把“双进程”当成数据安全证明。

## 2. 身份、工作空间与执行

- 复用 DeepSeek 账号身份，不另做注册、找回密码或设备证书体系。设备可查看、可一键吊销。网络接入采用已讨论的 Tailscale 方案，服务绑定明确地址，不默认暴露所有网卡；**网络成员身份不等于应用登录授权**。
- **待澄清的接入细节**：聊天记录同时出现“首次六位码”和“不做配对码”。在认证流程、账号与设备信任关系写清前，不据此改现有认证，也不声称已经无缝登录。
- 一个 Bot 就是一个工作空间，持有指令、记忆、工具、文件和任务；每个 Bot 有模型画像，按模型能力适配上下文与工具。模型可选本地、免费、付费或自定义，不绑死本地；手选为主，自动路由可选且规则可调。主协调模型和子任务模型分别配置。
- 子任务先提议再启动；明确执行设备、沙箱、网络与密钥权限。任务以等处理、运行中、待审、待合并、空闲、完成聚合，消息内任务卡能进入过程；暂停、归档、删除语义不同，完成任务一周无活动后可归档。任务要持续跟进或明确失败，不得静默丢失。
- 现有风险门继续执行。权限默认行为的历史表述有冲突（默认放行与读/写/危险三级），**不在本文件替用户改变安全默认值**；最终策略需单独确认。秘密通过安全存储注入，不进入聊天、提示词或诊断包。

## 3. 数据与文件：复用现有资产，补齐缺口

DSH 会话追加式 JSONL 仍是真相源，不另造一套会话事件日志。同步层在它上面维护可恢复索引（全局游标、对象版本），不是第二个真相源。搜索在服务器执行，索引可持久化并能从真相源重建。每个端最终要保留完整可读副本、可导出、可直接迁走；正常同步失败时允许用户让 AI 协助迁移，迁移不能丢原件或泄露凭据。记忆必须可查看、删除并验证删除结果。

| 缺口 | 必须提交的验收证据 |
| --- | --- |
| 没有请求级 since 游标 | 记录断线前游标，恢复后仅补缺失区间；过期游标显式降级；无重复无缺口。不能拿内核内部补洞等同于公共 since 接口。 |
| 无对象版本冲突反馈 | 两端从同一版本修改同一对象，过期写被明确拒绝/提示；保留用户草稿，不静默覆盖。 |
| 客户端无完整本地库/离线写队列 | 断网后旧记录与附件可读、可导出；离线操作入队，重连幂等提交；换账号/服务器不串数据；删除同步可验证。 |
| 检索索引默认内存库 | 重启前后查询一致，索引损坏可重建；不能把搜索设置已持久化当成索引已持久化。 |
| 巢 HTTP 下载无 Range | 大文件中断后带 Range 续传，验证 206、Content-Range、非法范围 416 及源文件变化时不拼错文件。 |
| App 缺大文件上传入口 | 聊天输入框“+”选文件，消息内显示进度与文件卡；断线/进程重启可续传，完成做整文件校验，内容不进入模型上下文。 |

已有设备传输的 4 MiB 分块、整文件 SHA-256、幂等 ID、journal 偏移续传及取消/重试继续复用，不重建 blob 服务。目标路径统一经巢中转；已有自动直连不能误报为目标形态。秒传/缺块跳过需另有实现与测试，整文件哈希本身不代表已有秒传。

切会话另单独验收：预热 20 会话（长输出、图片、生成中），每次停 1 秒；点击到首屏内容 p95 <100ms，预热后切换不新增快照。还要验证隐藏会话生成、断网 10 秒恢复、超过 64 会话淘汰、换服务器清空及 64 会话内存占用。连接级缓存只解决导航体验，**不等于完整本地副本，也不等于 since 协议**。

## 4. 工具、原生设置与开放性

Tool Ultra 统一目录、按需加载、风险门和设备命名空间；MCP 与外部控制/诊断接口保持开放、独立鉴权、可吊销。外部 AI 可调试，但不等于能绕过用户权限。DSH 已有设置只加导航、保留原生页面与后端写入语义，不复制表单；Swiftnest 只拥有设备、传输和产品层配置。字段归属见 [设置边界](./settings-ownership.md)。

候选预装清单：`dsh-context`、`dsh-genui`、`modlens`、`modsearch`、`dsh-model-router`、`dsh-market`。**清单不是安装许可或已核验结果**：正式接入前核对真实包/仓库与许可证，固定版本/commit，审文件、网络、执行及凭据权限，验证卸载回退与 UI；先核验 market、context。此处不复制尚未独立核实的星数与“风险最低”结论。不并入重复客户端/团队/记忆系统或越狱插件。

## 5. 界面结构与交付检查

| 插槽 | 内容与扩展边界 |
| --- | --- |
| 顶栏 | 当前标题、全局动作；手机只留一个标题与一个主按钮。 |
| 左侧列表 | Bot、会话、设备的导航面板。 |
| 主区 | 聊天或功能页面，保持阅读宽度。 |
| 右侧栏 | 上下文、任务、文件；窄屏进入抽屉。 |
| 浮层 | 预留通知中心、命令面板、任务面板的位置与焦点/关闭规则。 |

新功能通过插槽注册面板，不重排主布局、不接管其他插槽。面板需声明稳定 ID、插槽、最小可用宽度和生命周期；具体注册 API 尚未实现。第三方 UI 使用公共组件和令牌，不兼容时放入标准容器，容器不等于安全沙箱。遵守 [11 条界面规范与自适应验收](./ui-kit.md)。

升级由服务器协调客户端版本、能力协商和兼容降级，客户端不能随意执行服务器下发脚本。备份采用可公开解析的标准归档与 manifest（具体格式待评审），包含 JSONL、记忆、附件及校验；一键诊断包应脱敏。整体交付同时检查升级回退、迁移恢复、离线副本、设备吊销、权限、搜索、文件续传和 Linux/Android 真机体验，不把单测通过当作产品完成。

明确不做：多租户、独立注册体系、企业权限、收费运营与社交。源码体检只列问题，见 [现有三页检查](./ui-audit.md)。
