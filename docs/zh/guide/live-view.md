# 实时画面与接管控制

[English](../../en/guide/live-view.md) | 简体中文

在主人 App 与小艾的聊天页，点击 **实时画面 · 电脑名称**。支持屏幕功能的在线电脑会显示在聊天记录
上方；手机上全屏打开，桌面上在右侧打开。手机原生 App 可以观看电脑，Android 暂不提供自身屏幕。
局域网实时画面要求原生 App 和网页都通过 HTTPS 连接服务器，以保护流密钥交换；只有本机开发
地址允许明文 HTTP。

## 在电脑上开启

1. 按[控制这台电脑](./control-this-computer)完成桌面 App 配对。
2. 开启 **允许 Ivy 控制这台电脑**，再单独开启 **允许实时画面**。实时画面默认关闭。
3. 保持桌面 App 运行。屏幕和输入功能要求托盘可用；有人观看时，托盘变为红色并发送开始通知，
   **此设备**中也会显示控制状态。
4. 在托盘或**此设备**点击 **停止实时画面**，即可关闭连接、关闭实时画面开关、停止屏幕后端并释放
   接管权。再次允许观看需重新打开开关。关闭设备控制、取消配对或退出 App 也会断开连接。

只有主人 App 会话能打开实时画面。代理工具无法访问观看入口或授予自己接管权限。桌面画面可能包含
共享文件夹之外的私人窗口；文件夹限制约束文件和终端工具，不会遮挡屏幕像素。分享前请收起秘密信息。

## 在手机上操作

初始状态是 **小艾正在控制**，此时可观看、双指缩放和平移。点击右下角 **接管控制** 后，电脑先暂停
代理输入，再确认 **你正在控制**。接管期间即使批准代理输入，调用也会返回 `OWNER_HAS_CONTROL`，
不会在交还后补执行。点击 **交还给小艾**恢复代理输入。关闭或断开观看连接会释放控制权，故障时显示
**已暂停**。

- 轻点为左键，按住至少半秒为右键。
- 接管时单指拖动模拟鼠标拖动；仅观看时单指平移画面。
- 双指张合缩放；接管时双指同向移动滚动，仅观看时则平移。
- **键盘**打开文本框和按键。输入文字后点击发送；支持回车、退格、Tab、Escape、方向键以及
  ctrl+c/ctrl+v。**适应屏幕**重置缩放和平移。

每台电脑仅允许一个观看者，观看会话最长一小时，之后可重新打开。显示器断开后请重新打开面板。
默认观看主显示器，SDK 还可指定 `displayId`；面板内的显示器选择器尚未实现。

## 小艾的工具与坐标

`screen.screen_info`返回显示器标识、尺寸、缩放和后端。`screen.screen_capture`在
`result.data.data`中返回 PNG/JPEG 的 base64 数据，同时返回 `mime`、`width`、`height`、
`scaleFactor`、`region`、`displayId`和`captureId`。`maxDimension`默认 1280，最大 2560，
不会放大原图；区域使用原显示器像素。屏幕内容标为不可信，方便后续交给视觉模型处理。

`input_click`、`input_move`、`input_drag`、`input_scroll`、`input_type`、`input_key`均为
`exec`风险，默认需要批准。定位工具使用`displayId`、`captureId`和截图像素空间中的`x/y`；
拖动还需`toX/toY`。主机保存裁剪和缩小关系，检查边界，显示器几何变化后拒绝旧坐标。
滚动使用像素`dx/dy`，文字按原文输入，按键可写`Return`或`ctrl+c`。

## 后端与依赖

| 会话 | 采集 | 输入 | E2b 验证情况 |
| --- | --- | --- | --- |
| Linux wlroots 协议（含 niri/labwc） | grim 1.5，wlr-screencopy 或 ext-image-copy-capture | 绑定输出的虚拟指针 v2、wtype 虚拟键盘 | 无头 labwc/pixman 真实端到端通过 |
| Linux GNOME/KDE Wayland | ScreenCast Portal + PipeWire/GStreamer | RemoteDesktop Portal | 编译通过，待真实桌面验证 |
| Linux X11 | XGetImage | xdotool/XTest | 编译通过，待 X11 验证 |
| Windows | GDI 回退 | SendInput | 已实现，待 Windows 工具链和硬件验证 |
| macOS | 暂不支持 | 暂不支持 | 不公布屏幕和输入能力 |

按当前会话协议选择后端，不会悄悄改用 XWayland 截取不完整桌面。Portal 会弹出系统权限选择器，
选择一个显示器并申请键盘和指针权限，不保存恢复令牌。其尺寸和缩放描述归一化的流，不代表物理 DPI。
可以在电脑上取消 Portal 授权。GNOME/KDE 可能拒绝控制受保护界面；Windows 的 UAC、安全桌面或更高
权限窗口也无法由 SendInput 控制。

默认`nix develop`已提供 grim、wtype、GStreamer（含 pipewiresrc）与无头 labwc。发布 Linux App
时仍需将这些辅助程序放入 App 的 PATH。缺少依赖或协议会明确报错，不使用特权输入守护进程，
也不会尝试系统级安装。

实时画面使用 JPEG，仅发送变化帧，同时最多一帧等待确认。局域网目标为 10–15 fps，实际速度受采集
和编码开销影响；确认延迟会降低画质（80 至 35）和帧率。视频、主人输入、工具回复走独立且有界的
传输队列。H.264/WebRTC、Linux 辅助程序打包、实体手机性能测量与更多后端的硬件验证仍需后续完成。
可续传文件流属于 E2c，本次未启用。
