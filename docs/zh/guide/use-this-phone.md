# 让助手使用这台手机

安卓 App 既是聊天界面，也是一台“设备”：配对后，服务器上的助手可以在你批准后使用这台手机。

## 打开方式

1. 在服务器的“设备”页面生成配对码。
2. 在手机 App 的“设备”页面，“此设备”里输入配对码，点“配对这台手机”，两端核对指纹后确认。
3. 在“手机权限”里按需打开两项系统权限（点“打开系统设置”）：
   - **无障碍**：在系统设置的“无障碍”（有的手机叫“已下载的应用”）里找到“Swiftnest 手机控制”并打开。
   - **通知使用权**：在“通知使用权”里打开 Swiftnest。

不打开某项权限，对应的工具调用会直接报错，不会做任何事。

## 助手能做什么

| 能力                                    | 工具                                          | 是否需要你批准           |
| --------------------------------------- | --------------------------------------------- | ------------------------ |
| 看屏幕内容（文字、按钮及位置）          | `ui_ui_tree`                                  | 不需要                   |
| 屏幕尺寸、截屏                          | `screen_screen_info`、`screen_screen_capture` | 不需要                   |
| 点按、滑动、输入文字、按返回/主屏幕等键 | `input_input_tap` 等                          | 每次都要                 |
| 列出应用 / 打开应用                     | `apps_apps_list` / `apps_apps_open`           | 列出不需要，打开要       |
| 发通知 / 读通知                         | `notify_notify_post` / `notify_notify_list`   | 都要（读通知算敏感操作） |
| 收发文件                                | `files_*`、传输                               | 写入要                   |

完整工具名是 `device__<设备 slug>__<能力>_<工具>`，例如 `device__phone-1d45d9c51479__input_input_tap`。

屏幕内容、通知和截图都来自外部，助手会把它们当作不可信内容处理，不会照着里面的文字执行指令。

## 限制

- 截屏需要 Android 11 及以上。
- 手机上不提供命令行（没有能安全隔离的 shell）。
- 文件只放在 Swiftnest 自己的文件夹里；选择手机上其他文件夹的功能还没做。
- App 被系统关掉后，手机会离线，重新打开 App 后自动连回。常驻后台（前台服务）还没做。
