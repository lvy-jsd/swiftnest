# 控制这台电脑

[English](../../en/guide/control-this-computer.md) | 简体中文

桌面 App 是 **Perch（栖点）**，只控制安装它的电脑。中央 Swiftnest Server 是 **Nest（巢）**。
控制默认关闭，初始不共享任何文件夹。网页 App 可以管理设备，但不会提供本机控制；Android 暂时隐藏此界面。

1. 用服务器的 App 配对链接连接桌面 App，打开 **设备 → 此设备**。
2. 设置显示名称，选择 **添加共享文件夹**，保存更改。文件工具与命令只能使用这些文件夹；密钥、凭据、
   浏览器资料与 Swiftnest 自身数据始终受保护。
3. 在服务器的 **设备** 页面选择 **配对设备**，复制设备连接地址与六位配对码。本机地址按已连接服务器
   和默认设备端口 7711 预填；如果使用其他端口或 TLS 入口，请替换成服务器显示的地址。
4. 在 **此设备 → 配对这台电脑** 中输入配对码，这会开启设备控制。将此处服务器指纹与服务器页面核对，
   选择 **指纹一致**；同时在服务器核对此电脑指纹并确认。两端都确认才完成配对。配对码五分钟有效且仅用一次。
5. 显示 **在线** 后，Ivy 可列出、读取文件并运行只读命令。写入与其他执行操作会等待主人在设备页或聊天
   审批横幅中批准。请查看原始参数后决定。

关闭 **允许 Ivy 控制这台电脑** 会立即断开连接并取消运行中的调用，同时保留配对，方便以后开启。
**取消此电脑配对** 还会忘记本机保存的 Nest 公钥；若要删除服务器记录，请在服务器使用 **撤销设备**。
修改显示名称不会改变设备身份或稳定的工具命名空间。服务器公钥变化会停止重连，需要重新核对并配对。
保存设置会重启设备连接，请先完成正在运行的工作再修改文件夹或名称。

## 后台与平台限制

开启 **在后台保持运行** 后，关闭窗口仅隐藏窗口，Rust 任务仍在 App 进程中运行；可从托盘重新打开或退出。
Linux 需要支持 StatusNotifier/AppIndicator 的托盘，Windows 使用通知区域。创建托盘失败时无法开启后台选项。
macOS 使用菜单栏图标，但行为仍需实机验证。休眠、注销、退出或终止进程会断开设备；不会安装开机启动或系统服务。

Linux 命令执行需要 App 的 PATH 中有 bubblewrap（`bwrap`）并允许用户命名空间；Nix 开发环境已包含它。
缺少沙箱会拒绝执行。macOS 使用平台 `sh` 与 `sandbox-exec`，仍需平台验证。Windows 文件工具可用，命令执行
暂时拒绝，等待可隔离文件系统的执行器；选定的 Windows 命令语法为 `cmd.exe /D /S /C`。
即使批准命令，也不能访问共享文件夹之外的用户文件。沙箱允许读取执行所需的系统程序和库。
命令输出最多 64 KiB，文件读取最多 512 KiB。截屏、键鼠输入、实时画面、接管及大文件传输留待后续任务。

配对数据与设备私钥保存在 Tauri App 数据目录的 `perch/` 下，请保持目录私密。目前通过操作系统文件权限保护
私钥，后续接入系统密钥环。设备核心不依赖 Node。服务器审批与审计见[设备指南](./devices)。
