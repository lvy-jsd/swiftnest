# 记忆

在桌面、手机或网页 App 主菜单中打开 **记忆**。你可以添加、编辑、删除单条事实，或打开主题编辑 Markdown。被拒绝的改动会显示服务器的原因。所有 App 共用服务器记忆，不在各端另存一套。

助手可以调用 `remember`（文本及可选主题）、`forget`（条目文本或 id）、`recall`（列出全部、用 `query` 搜索，或用 `topic` 读取整个主题）。在相同位置重复保存相同文本，只会安静地提示已保存过。

**自动记住重要的事**默认开启。聊天安静两分钟后，会由该聊天原本使用的主模型审阅新增消息，只提取所有者值得长期保留的偏好、人物关系、项目和长期指示。审阅时提供现有事实，较新的相反事实会按 ID 替换旧条目。不会接入额外模型服务；记忆保存在服务器上，整理使用聊天已有的模型（如果聊天用云端模型，审阅仍会发送给同一家服务商）。整批提议必须先通过严格 JSON 校验、密钥拦截和存储限额检查，之后才能保存。

在记忆页面用开关暂停或恢复审阅。**最近自动记住的**展示最近 50 条仍保留的自动记忆及日期，点一次删除即可通过原有删除路径移除。“更多记忆选项”中可以编辑主题。服务器将开关和各聊天的审阅游标持久化到 `memory/auto.json`；事实与游标通过同一可恢复事务推进。所有聊天共用一个审阅队列，同一时间最多进行一次审阅；排队期间有新回合时，会重新等待静默期。重启后也会检查尚未重新打开的安静聊天。启用时间也会持久化：首次启动不回溯旧记录，重新开启后只审阅新消息，不补录关闭期间的消息。新回合会取消正在进行的审阅；失败只记录不含内容的警告，一分钟后重试一次，之后等待新回合、开关变化或重启。回合进行中不会审阅。

可以用 `memory: { auto: false }` 或 `SWIFTNEST_MEMORY_AUTO=false` 设置初始默认值，环境变量优先于 YAML。App 中明确保存的开关选择优先于这个默认值。配置只接受布尔值。疑似密钥不会保存；与手动记忆一样，你可以检查并删除不想保留的事实。

每个会话首次渲染提示词时冻结记忆块。之后保存的新记忆不会改变该会话的系统提示词，以便保持前缀缓存。提示词要求助手在针对过去的偏好或事实回答“不知道”之前先调用 `recall`。新会话会看到最新记忆，`recall` 始终读取最新内容。

数据位于 `<home>/memory/`：`MEMORY.md` 保存简短事实，`## Index` 用 `[[主题]]` 链接详情；`topics/<主题>.md` 保存主题；`snapshots/<sessionId>.md` 保存冻结块。每条事实占一个列表行，行尾有 `[source: …; added: …; id: …]` 元数据。App 主题编辑器支持每行一条事实，也可带 Markdown 列表符和标题，保存时会补齐元数据。

按 Unicode 字符计数：单条最多 300 字，`MEMORY.md` 最多 4,000 字，每个主题最多 16,000 字，最多 40 个主题。疑似 API 密钥、令牌、私钥、密码的内容会被拒绝，请将凭据存放在对应的秘密存储中。

删除一条记忆会将它从服务器的所有位置移除。

编辑或遗忘会从所有冻结块移除旧行；DSH 移除会话时会删除对应快照，启动时也会清理超过 30 天的快照。

每次改动先写 `pending.json`，再替换相关文件，最后向 `journal.jsonl` 追加一次事务，只记录事务 ID 和时间，不保存记忆原文，日志只保留最近 200 次事务。启动时以及下次读写前会补完中断的事务，不会重复应用已提交的事务。不完整日志行和旧的 `journal.torn` 会被丢弃，恢复使用 pending 文件，提交后会删除 pending 文件。请在服务器停止后备份整个记忆目录，不要在服务器运行时并行手改文件。

记忆是内置功能，默认启用，无需安装或配置。它的开关独立于第三方 `plugins` 配置。要关闭工具和提示词记忆块（记忆页面会显示已禁用），设置：

```yaml
memory:
  enabled: false
```

或使用 `SWIFTNEST_MEMORY=false`，已有记忆仍保留在服务器。仅所有者可访问 HTTP API，使用与其他 App API 相同的签名会话和 Host/Origin 检查：`GET /swiftnest/api/memory`，该前缀下的 `POST /add`、`/edit`、`/delete`，以及 `GET`/`POST /topic`。`packages/api` 提供对应的类型化方法。

自动记忆新增仅所有者可用的 `GET`/`POST /swiftnest/api/memory/auto`（`{ enabled: boolean }`）和 `GET /swiftnest/api/memory/auto/recent`。客户端方法是 `memoryAutoSettings`、`setMemoryAuto`、`recentAutoMemory`，删除仍使用 `deleteMemory`。
